# Release 0.1.476, 2026-10-27

The frozen build inputs are commit `7793938` plus the working-tree version
increments and the one-line Swift access-control repair. The previous local
0.1.475 and 0.1.106 packages contained earlier source; they were preserved,
not replaced with different bytes. Android build 270 had already been
published, so this release uses build 271.

## Verification

- Python source suite: 1,240 passed, 318 subtests passed. The actual staged
  0.1.107 runtime separately passed 207 tests and 63 subtests; 88 additional
  packaging and queue tests passed after the version increments.
- Relay suite: 49 passed and two PostgreSQL integration tests skipped. A
  separate SQLite migration completed through `0006_device_login`.
- macOS: 703 native tests in 63 suites passed; interactive/focus-changing
  suites were not run. The release archive passed strict signature,
  version, resource-rendering and unpacked-archive checks.
- Android: release build and 274 debug unit tests passed; APK version and the
  existing signing-certificate fingerprint were verified.
- Manifest SHA-256 values were checked against all referenced artifacts.

## Remaining Boundary

The live pcrd is still congested on historical reads, and one earlier stop
command remains journaled as `started` even though the two explicitly stopped
Agents and their detached worker have reached their requested state. No
command, prompt, or original worker was replayed to force an upgrade. The new
client can therefore show cached or unverified workspace status until the
manager is safely recovered. The plugin's existing shared interpreter also
has active MCP processes; its runtime was not overwritten in place.
